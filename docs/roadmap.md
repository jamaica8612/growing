## 🔨 지금 진행 (외부 API 불필요)

### 메시지 템플릿 설정화
- 현재 `Messaging.tsx`·`Attendance.tsx`에 하드코딩된 등원/하원/숙제/보강/평가 알림 문구를 `growing_settings.message_templates`(jsonb)로 분리하고, 안전 백업 설정 화면에서 편집·저장.
- **전략적 이유**: 카카오 알림톡은 사전 승인된 템플릿이 필수 → 지금 템플릿을 데이터로 빼두면 알림톡 연동 시 그대로 재사용.

### 출결 캘린더 뷰
- 기존 출결 데이터를 월간 달력 그리드로 시각화. 날짜 클릭 시 일자별 기록으로 점프.
- 순수 UX 개선, 신규 데이터 없음.

## ⏸ 보류 (외부 의존성 — 준비되면 착수)

### 1. 문서/리포트 PDF 생성
- **선행 조건**: 학원에서 실제 쓰는 청구서·리포트 **양식 입수**
- **방향**: 저토큰 원칙 — AI는 요약/코멘트만 생성하고, 표·PDF 레이아웃은 코드 템플릿이 조립. `html2pdf` 등 로컬 라이브러리(네트워크 불필요).
- **건드릴 곳**: `Students.tsx`의 월간 리포트(`window.print()` → 자동 PDF), 신규 문서 템플릿 모듈

### 2. 결제선생 API 연동 (수납/미납 자동화)
- **선행 조건**: 결제선생 **API 키 발급**
- **방향**: 현재 수동 "수납 처리"를 외부 거래 확인으로 대체/보강. 거래번호·영수증 URL 등 필드 추가 예상.
- **건드릴 곳**: `growing_payments` 스키마(`external_transaction_id`, `receipt_url` 등), `Payments.tsx`, `api.ts` 결제 함수, 신규 Edge Function(웹훅/조회 중계)

### 3. 카카오 알림톡 연동 (자동 발송)
- **선행 조건**: 카카오 **비즈니스 채널 + 알림톡 템플릿 사전 승인**
- **방향**: 현재 "복사 → 수동 붙여넣기"를 API 자동 발송으로. 메시지 템플릿 설정화(위)가 그대로 알림톡 템플릿으로 매핑됨.
- **건드릴 곳**: `growing_kiosk_alerts` 발송 상태 필드(`sent_at`, `sent_via`), `Messaging.tsx` 대기열 발송 버튼, 신규 Edge Function(알림톡 발송 중계)

## 💡 설계 원칙 (유지)

- **모델 티어링**: Gemini `2.5-flash-lite`(라우터·조회) + `2.5-flash`(종합·작성). 단일 학원 규모 월 ~$2~5. Gemini 1.5/2.0 계열은 셧다운이라 사용 금지.
- **쓰기 자율성**: 모든 DB 변경은 제안 → 원장 승인 → 실행 (human-in-the-loop).
- **저토큰 문서 생성**: AI는 요약/코멘트만, 표·레이아웃은 코드 템플릿이 조립.
- **수정 범위**: DB 데이터 + 문서 생성. 실제 소스코드 자동 수정은 제외.
- **격리**: 모든 테이블 `growing_*` prefix, `owner_id` RLS로 사용자별 분리.
