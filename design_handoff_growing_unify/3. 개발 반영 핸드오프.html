★ 새 기능 (채택: 1·4·6)

기존 데이터/스키마 위에 얹는 추가 기능 — 프로토타입에 목업 반영됨.

① 아이비 카카오 자동응답 — KakaoManager.tsx + Assistant 신규
  • 연동 설정에 자동응답 토글(.ka-switch). ON이면 출결·숙제 문의(type: attendance|homework)는 아이비가 DB 조회 후 즉시 자동 답변 — 요청 큐에서 "자동 처리됨"으로 표시되고 대기 수에서 빠집니다. 상담·연결 요청은 자동 처리하지 않고 큐에 남깁니다.
  • 실제 구현: Edge Function(kakao-skill)에서 요청 의도 분류 → 출결/숙제면 DB 조회 답변, 그 외는 pending으로 큐 적재. 기존 kakaoParentRequests 흐름 재사용.
④ 월간 성장 리포트 — CounselLogs.tsx (모달) 신규
  • 상담/진도 화면 툴바에 "월간 리포트" 버튼 → 모달(.rp-*). 학생 선택 시 출석률·숙제 수행률·평가 추세·상담 하이라이트를 그 달 데이터로 집계(규칙 기반, AI 호출 없음). 인쇄/PDF + 종합 알림장으로 전송.
  • 집계 소스: attendance(출석률·숙제), counselLogs(평가·상담). README의 "월간 리포트" 항목과 일치 — 기존 reportSummary.ts 재사용 가능.
⑥ 반 정원 + 대기자 — Classes.tsx + 타입 신규
  • Class 타입에 capacity: number, waitlist: string[] 추가. 클래스 카드에 재원/정원 바(.cls-cap) + 정원 마감 배지 + 대기자 칩(.cls-wait). 정원 차면 신규 배정 막고 대기자로.
  • Supabase classes 테이블에 capacity/waitlist 컬럼 마이그레이션 필요(기본값 적당히).

📱 태블릿 브레이크포인트 수정 (중요)

PWA를 태블릿에서 쓸 때 모바일로 무너지는 문제 — 원장님 직접 확인.

src/index.css 브레이크포인트
  • 증상: 현재 모든 모바일 전환이 @media (max-width: 768px)입니다. 아이패드 세로(768~834px)·중소형 태블릿이 이 범위에 걸려 핸드폰 단일 컬럼으로 보입니다. 태블릿은 화면이 넓으니 풀 레이아웃이 맞습니다.
  • 해결: 모바일 붕괴 기준을 768px → 600px(또는 640)로 낮춰 진짜 폰만 단일 컬럼으로. 601~1024px(태블릿)은 데스크탑 레이아웃을 받고, 이미 있는 @media (max-width:1024px / 1200px) 컬럼 축소 규칙으로 자연히 정리됩니다.
  • 적용 범위: 일괄 치환 — 단, 하단 탭·드로어 같은 모바일 전용 내비 표시 기준은 그대로 두거나 별도 관리(태블릿에선 사이드바 노출이 자연스러움).
  • 프로토타입 상단 "태블릿" 토글로 목표 모습을 확인하세요 — 사이드바 + 2단 본문이 그대로 유지됩니다.
/* index.css — 모바일 붕괴 기준 하향 */
@media (max-width: 768px) { ... }   // 변경 전 — 태블릿도 모바일
@media (max-width: 600px) { ... }   // 변경 후 — 폰만 모바일, 태블릿은 풀 레이아웃

/* 태블릿 구간(601~1024)은 기존 컬럼 축소 규칙이 처리 */
@media (max-width: 1024px) { /* 그리드 2→1 또는 축소 */ }
